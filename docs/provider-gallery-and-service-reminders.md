# 达人多媒体资料与履约提醒

## 业务规则

- 达人资料支持 1–9 个有序素材，其中最多 3 个视频。首项必须为照片，用户端列表、收藏、足迹统一以此为封面。
- 图片沿用 JPG/PNG/WebP、8MB 限制；视频支持 MP4/MOV、50MB。上传端校验容器、视频轨道及媒体数据，不做转码或人脸识别；建议使用兼容性更好的 H.264 MP4。
- 增删媒体、调整顺序均随资料修订审核；待审核、驳回不会覆盖已发布资料。首次综合开通审核与后续资料审核都会原子发布完整媒体列表。
- 用户详情支持左右滑动、点击图片预览、手动播放视频；切换素材或离开页面暂停视频。
- 达人接单弹窗要求实名认证本人履约，禁止代接、转单；上传集合照前提示照片必须清晰包含本人及到场环境。后端仍强制先上传履约照才能开始服务。
- 达人“我的”名称旁展示实际评分，无评分时显示“暂无评分”；账号设置展示平台记录的信用分，不做客户端推算。

## 接口兼容

- `PATCH /api/v1/providers/me/profile/` 新增 `media_ids: UUID[]`，顺序即展示顺序。素材必须属于当前用户，且为已上传的公开达人照片或视频。
- 自己的资料、用户端详情、后台审核详情返回 `media: [{id, type, url}]`。`type` 为 `image` 或 `video`。
- 保留 `lifestyle_photo_id/url`，与首张照片同步；旧客户端仅更换生活照时保留其他素材，仅修改文字时保留全量媒体。
- `POST /api/v1/media/provider-videos/`：已通过达人申请的账号可 multipart 上传，字段 `file`，返回 `{data: {id, url}}`。
- 工作台新增 `rating`、`credit_score`；账号安全新增 `provider_credit_score`（无达人资料为 null）。

## 发布与验收

1. 先部署后端并执行 `uv run --env-file .env python manage.py migrate --settings=config.settings.local --noinput`。新增迁移为 mediafiles 0002、providers 0017/0018；旧生活照自动成为首张图片，历史待审核修订也回填。执行前确认目标环境并按常规流程备份。
2. 网关请求体上限需覆盖 50MB 视频及 multipart 开销（建议至少 60MB），上传超时需覆盖慢网；客户端视频上传超时为 180 秒。确认 COS 视频读取与微信小程序媒体域名配置可用。
3. 同步发布后台、用户端和达人端。当前任务只增加迁移文件，不自动修改业务数据库。
4. 真机验收：一次多选照片、MP4/MOV 上传、调整首图、混排图片与视频、视频播放后滑动/退页停止、审核前后公开内容、拒绝接单弹窗不发请求、缺少履约照无法开始、信用分与后台一致。
