# 首页城市与搜索（2026-09-29）

## 本轮实现

- 后台「平台参数 → 发现页 · 开通城市」独立保存城市配置，支持添加、移除、排序；第一项是默认浏览城市。沿用 `operations.manage` 和全数据范围校验，修改写入审计日志。
- 新增 `GET /api/v1/locations/cities/`，只返回开通城市的编码、名称，不需要登录。首发默认仅开放邯郸（`130400`），其他城市后续可在后台扩展。
- 新增 `POST /api/v1/locations/locate/`，接收 WGS84 GPS 经纬度，由服务端转为 GCJ-02 后调用腾讯逆地理编码。返回城市、是否开通和 GCJ-02 坐标；不返回街道地址，不保存定位记录，响应 `no-store`。沿用地图 IP 限流（默认 30 次/分钟、500 次/天）。
- 用户端城市页支持名称/编码搜索、手动切换和主动定位；失败/拒绝授权/超时/未开通城市均保留原选择，并允许手动浏览。
- 首页搜索打开独立「同城搜索」页，分别搜索达人、活动；支持清空、最近 10 个搜索词、空结果、重试和分页。没有场馆业务，所以移除首页的“场馆”搜索承诺。
- 达人列表、活动列表、活动频道均接上分页；切换筛选重置分页，追加失败保留已有记录并重试原页，过期请求不覆盖新结果。

## 位置语义

1. 手动选城不生成城市中心坐标：无明确位置时仅发送 `city_code`，用于同城浏览；不支持无坐标的距离排序，点击距离排序引导定位。
2. 用户主动定位后，在内存中使用该位置 10 分钟；只持久化城市，不持久化精确 GPS 坐标。跨城市手动切换清除定位。
3. 没有有效定位时，登录用户可以使用同城默认地址（无默认项时沿用首个常用地址）。手动选定的其他城市不会被默认地址覆盖；页面显示实际位置来源。
4. 有明确位置时继续调用既有 `within_service_radius`，按各达人的服务半径过滤。仅浏览城市不代表可在任意地点下单；下单时仍按用户选定服务地址及实际路线距离校验服务范围，未改动该校验。
5. 后台移除城市仅关闭发现入口，不删除活动、订单，也不作为订单接口的城市授权机制。

## 发布顺序

1. 发布 API 并通过现有生产部署流程执行迁移 `backoffice.0029_platform_discovery_cities`；本轮未对业务库执行迁移。
2. 发布管理端及 H5。请先完成后端迁移，新客户端依赖城市接口，不会在接口错误时静默搜索全国。
3. 后台「平台参数」检查开通城市，用「保存城市配置」独立保存；配置不会修改活动标签或达人服务分类。默认值仅对尚未保存城市配置的初始化场景生效，不覆盖已有配置；若此前已保存北京、上海，首发时需在后台移除并保存，仅保留邯郸。
4. 验证后端原有腾讯地图 WebService Key / SK 有效。网页定位需要浏览器允许位置权限及可用的定位环境；定位失败仍可选城。
5. 原生 App 新增系统定位模块、Android 前台定位权限和 iOS 使用说明，需要重新打包/安装验证，不仅更新 H5。部分 Android 设备系统定位能力有限，必要时另行配置获授权的地图厂商原生定位 SDK。[DCloud 定位说明](https://uniapp.dcloud.net.cn/tutorial/app-geolocation.html) · [manifest 配置](https://uniapp.dcloud.io/tutorial/app-manifest)

## 验证

- 后端：`uv run --env-file .env pytest locations home providers activities -q --reuse-db`。使用独立测试库，地图接口模拟，覆盖配置校验/权限/审计、游客限流、坐标转换、按城市搜索分页、服务半径等。
- 用户端：`npm run test:discovery`、`npm run type-check`、`npm run build:h5`、`npm run build:app`。
- 管理端：`npm run build`。
- 浏览器：以 `VITE_API_BASE_URL=/api/v1` 构建 H5 后运行 `node tests/discovery.browser.cjs`（位于用户端工程）。需要可用的 Playwright；可通过 `DAZZY_PLAYWRIGHT_MODULE` 指向已安装模块、`DAZZY_BROWSER_PATH` 指定浏览器、`DAZZY_SCREENSHOT_DIR` 指定截图目录。测试自建本地静态服务，拦截所有 API、阻止外部请求，不连接业务服务。
- 浏览器验证不替代微信内 H5 和 Android/iOS 真机位置授权验证；上线前应各测一次允许定位、拒绝定位、重新定位。

界面沿用现有组件与色彩，按 apple-design / emil-design-eng 保留明确的位置来源、最小触控区域与即时反馈；高频搜索和切换不添加延迟动画。
