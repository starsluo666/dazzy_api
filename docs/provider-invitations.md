# 达人邀请：第一阶段上线说明

## 业务口径

- 门店、已通过入驻初审的达人可邀请新手机号账号；共用**达人端** `pages/invitations/provider-register`（免登录）。用户端原有“成为达人”入口保持不变。
- 注册后直接在达人端 `pages/invitations/application` 查看入驻初审进度。未通过初审的账号再次登录或打开工作台时进入进度页；初审通过后进入工作台完善接单资料。审核被驳回显示原因，需联系平台核对；不重复注册或重新绑定邀请人。
- 手机号短信校验、密码、真实姓名、出生日期（18～100岁）、男/女性别、近期生活照、已开放服务城市、协议同意一次提交。
- **注册且完整入驻意向提交成功**产生一笔待财务审核奖励，不要求先接单，也不把“入驻初审通过”冒充注册成功。入驻审核与奖励审核是两个不同流程。
- 金额单位为分，门店与达人金额分别配置；注册时锁定金额、规则版本、邀请来源名称和代码。之后调价、停用来源不修改历史奖励。
- 同一新账号只记录一次；已有手机号不能通过此入口重复注册/绑定。邀请来源不能在被驳回后修改。普通用户邀请送券不叠加触发。
- 奖励独立台账，不进入用户钱包、达人订单收入、汇付分账/提现；本功能无任何真实打款调用。

## 部署与配置

1. 更新 API 依赖并执行迁移（含 growth/0002、backoffice/0038），默认关闭活动、奖励金额为0。
2. 部署达人端 H5、管理后台；如使用达人小程序也需重新构建发布。二维码是普通 HTTPS 二维码，扫码进入达人端 H5，不是微信小程序码；小程序内可通过新页面路径和 `code` 参数进入注册页。用户端无需为本功能新增页面。
3. `PROVIDER_INVITE_H5_BASE_URL` 必须显式填写实际**达人端 HTTPS H5 根地址**（不带 `#`、查询参数、用户名密码）；没有默认域名，缺失或格式无效时不允许启用邀请/注册或生成二维码，已有奖励台账仍可查询和审核。若之前填了用户端地址，请改为达人端地址并重新下载二维码。生成邀请链接不依赖请求 Host。跨域部署时还需配置 API 的 CORS 允许来源；也可用同域 `/api/v1` 反向代理。
4. 后台「营销管理 → 达人邀请 → 奖励规则」分别设置门店/达人奖励后开启。
5. 「邀请来源 / 门店二维码」创建门店，下载二维码；真实印刷前扫码确认邀请人、链接、开放城市和上传均正常。
6. 达人端「我的 → 邀请达人」自动获得专属稳定邀请码，可以复制链接或分享二维码，查看本人脱敏邀请记录及待审核/待打款/已打款金额。

### 权限

- `provider_invite.view`：查看全平台来源及奖励台账。
- `provider_invite.manage`：配置奖励、创建门店、启停邀请来源。
- `provider_invite.review`：审核奖励通过/不通过。
- `provider_invite.pay`：登记实际人工打款结果。
- 后三项均须同时有查看权限，且组织必须为平台、数据范围为全部。区域/城市账号不能访问，即使错误授予 `*` 也不放行。
- 迁移仅为既有 `platform-admin` 全平台系统角色增加权限，不扩展普通客服或财务角色。其他角色在「账号与权限」按岗位单独授权。

## 财务操作

1. 待财务审核：核验真实新注册、意向资料、归属、金额及异常/重复身份风险，填写审核说明，通过后进入待人工打款。不符合要求则驳回并留原因。
2. 待人工打款：财务在线下核验门店合作主体/达人本人收款资料。**先查历史记录与银行流水、落实唯一经办人，再线下转账**。
3. 转账完成后「登记已打款」，填唯一转账流水号、实际打款时间、收款人核验说明，并明确勾选已完成线下转账。不要在备注中填写完整身份证/银行卡号。
4. 第一阶段一笔奖励对应一笔转账，不支持合并转账或拆分付款。流水号全局唯一；并发/重复登记只允许一笔状态迁移。已审核/已支付记录不允许覆盖重写。
5. **系统防重只作用于台账，不可能阻止两名人员在外部银行重复转账**；人工付款必须遵循单人经办、流水核对流程。第一阶段不自动核验银行到账，也不支持自动追回已打款奖励。

## 故障与安全边界

- 注册事务失败时账号、申请、奖励一起回滚；已上传成功的生活照尽力清理，清理失败记录日志供存储核查。
- SMS 验证码属于一次性缓存凭证，数据库回滚不会恢复它。上传失败后如验证码已失效须重新获取；请求超时但服务端可能已提交，提示“已注册”时用该手机号登录查看入驻申请，不能重新计奖。
- 身份真实性仍须平台初审、后续实名和财务核验；短信注册只能证明手机号控制权，不保证一人只持有一个手机号。不要无人审核直接付款。
- 邀请人的未审核/未打款奖励会阻止账号注销；停用接单资格后仍可查看已有奖励，但不能继续产生新邀请。
- 部署前备份；本次未运行生产迁移，未发送真实短信、未上传真实照片、未转账。
